# claude-plugins

Personal Claude Code plugin marketplace by Thomas Tastet.

## Plugins

| Plugin | Description |
|--------|------------|
| [tailwindcss-lsp](./tailwindcss-lsp) | Tailwind CSS language server |

## Installation

```
/plugin marketplace add 0xtlt/claude-plugins
```

Then install plugins via `/plugin`.
